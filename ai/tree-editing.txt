TREE EDITING
============

CRITICAL: Built-in methods for programmatic tree editing
- addNode: Add new nodes
- moveNode: Move nodes with subtrees
- removeNode: Delete nodes
- Automatic path management

ADD NODE
--------
<script>
  let treeRef;

  function addChild(parentPath) {
    const result = treeRef.addNode(
      parentPath,  // Parent path (empty string = root)
      {
        id: Date.now().toString(),
        path: '',  // Will be auto-calculated
        name: 'New Item',
        sortOrder: 100
      }
    );

    if (result.success) {
      console.log('Added node:', result.node);
      console.log('New path:', result.node.path);
    } else {
      console.log('Failed:', result.error);
    }
  }
</script>

<Tree bind:this={treeRef} {data} ... />
<button onclick={() => addChild('1.2')}>Add to 1.2</button>
<button onclick={() => addChild('')}>Add to Root</button>

addNode signature:
addNode(parentPath: string, data: T, pathSegment?: string)

- parentPath: Where to add (empty = root)
- data: Your data object (path auto-calculated)
- pathSegment: Optional custom segment (otherwise auto-generated)

Returns: { success: boolean, node?: LTreeNode<T>, error?: string }

MOVE NODE
---------
<script>
  function moveNode(sourcePath, targetPath, position) {
    const result = treeRef.moveNode(sourcePath, targetPath, position);

    if (result.success) {
      console.log('Moved', sourcePath, '->', targetPath, position);
    } else {
      console.log('Move failed:', result.error);
    }
  }
</script>

<button onclick={() => moveNode('1.2', '2.1', 'before')}>
  Move 1.2 before 2.1
</button>

<button onclick={() => moveNode('1.2', '2', 'child')}>
  Move 1.2 as child of 2
</button>

moveNode signature:
moveNode(sourcePath: string, targetPath: string, position: 'before' | 'after' | 'child')

- sourcePath: Node to move (includes all descendants)
- targetPath: Target node
- position: Where relative to target

Returns: { success: boolean, error?: string }

Positions:
- 'before': Insert as sibling before target
- 'after': Insert as sibling after target
- 'child': Insert as child of target

REMOVE NODE
-----------
<script>
  function deleteNode(path) {
    const result = treeRef.removeNode(path, true);

    if (result.success) {
      console.log('Removed:', result.node?.path);
    }
  }
</script>

<button onclick={() => deleteNode('1.2')}>Delete 1.2</button>

removeNode signature:
removeNode(path: string, includeDescendants?: boolean)

- path: Node to remove
- includeDescendants: Remove children too (default: true)

Returns: { success: boolean, node?: LTreeNode<T>, error?: string }

ORDER MEMBER
------------
CRITICAL: For proper sibling ordering, set orderMember

<Tree orderMember="sortOrder" ... />

const data = [
  { path: '1.1', name: 'First', sortOrder: 10 },
  { path: '1.2', name: 'Second', sortOrder: 20 },
  { path: '1.3', name: 'Third', sortOrder: 30 }
];

When moving nodes with orderMember:
- Tree auto-calculates new order values
- Uses midpoint between adjacent values
- Example: Moving between 10 and 20 → sortOrder = 15

HELPER METHODS
--------------
Get node by path:
const node = treeRef.getNodeByPath('1.2.3');
console.log(node?.data.name);

Get children of a node:
const children = treeRef.getChildren('1.2');
console.log('Children count:', children.length);

Get siblings (including self):
const siblings = treeRef.getSiblings('1.2.3');
const index = siblings.findIndex(s => s.path === '1.2.3');

Refresh siblings (re-sort):
treeRef.refreshSiblings('1.2');  // Parent path

Refresh specific node:
treeRef.refreshNode('1.2.3');

MOVE UP/DOWN
------------
<script>
  function moveUp(nodePath) {
    const siblings = treeRef.getSiblings(nodePath);
    const index = siblings.findIndex(s => s.path === nodePath);

    if (index > 0) {
      treeRef.moveNode(nodePath, siblings[index - 1].path, 'before');
    }
  }

  function moveDown(nodePath) {
    const siblings = treeRef.getSiblings(nodePath);
    const index = siblings.findIndex(s => s.path === nodePath);

    if (index < siblings.length - 1) {
      treeRef.moveNode(nodePath, siblings[index + 1].path, 'after');
    }
  }
</script>

COPY NODE (low-level)
---------------------
For most copy/paste workflows use the CLIPBOARD API below. This lower-level
method copies a single node + subtree directly to a destination.

<script>
  function copyNode(sourceNode, targetParentPath) {
    const result = treeRef.copyNodeWithDescendants(
      sourceNode,
      targetParentPath,
      (data) => ({ ...data, id: crypto.randomUUID() })  // transform each copy
    );

    if (result.success) {
      console.log('Copied root:', result.rootNode?.path, 'count:', result.count);
    }
  }
</script>

copyNodeWithDescendants signature:
copyNodeWithDescendants(
  sourceNode: LTreeNode<T>,
  targetParentPath: string,
  transformData: (data: T) => T,
  siblingPath?: string,
  position?: 'before' | 'after'
)

Returns: { success: boolean, rootNode?: LTreeNode<T>, count: number, error?: string }

NEW ITEM WORKFLOW
-----------------
Complete workflow for adding items:

<script>
  let treeRef;
  let selectedNode = $state(null);

  function addSibling() {
    if (!selectedNode) return;

    const parentPath = selectedNode.parentPath || '';
    const result = treeRef.addNode(parentPath, {
      id: crypto.randomUUID(),
      path: '',
      name: 'New Sibling',
      sortOrder: Date.now()
    });

    if (result.success) {
      // Select the new node
      selectedNode = result.node;
      // Optionally scroll to it
      treeRef.scrollToPath(result.node.path);
    }
  }

  function addChild() {
    if (!selectedNode) return;

    const result = treeRef.addNode(selectedNode.path, {
      id: crypto.randomUUID(),
      path: '',
      name: 'New Child',
      sortOrder: Date.now()
    });

    if (result.success) {
      // Expand parent to show new child
      treeRef.expandNodes(selectedNode.path);
      // Select the new node
      selectedNode = result.node;
    }
  }

  function deleteSelected() {
    if (!selectedNode) return;

    if (confirm(`Delete ${selectedNode.data.name}?`)) {
      const parentPath = selectedNode.parentPath;
      treeRef.removeNode(selectedNode.path);
      selectedNode = null;
    }
  }
</script>

<Tree bind:this={treeRef} bind:focusedNode />

<button onclick={addSibling} disabled={!selectedNode}>Add Sibling</button>
<button onclick={addChild} disabled={!selectedNode}>Add Child</button>
<button onclick={deleteSelected} disabled={!selectedNode}>Delete</button>

INLINE EDITING
--------------
Edit node name inline:

<script>
  let editingPath = $state(null);
  let editValue = $state('');

  function startEdit(node) {
    editingPath = node.path;
    editValue = node.data.name;
  }

  function saveEdit() {
    if (editingPath) {
      // Update your data
      data = data.map(item =>
        item.path === editingPath
          ? { ...item, name: editValue }
          : item
      );
      editingPath = null;
    }
  }
</script>

<Tree {data}>
  {#snippet nodeTemplate(node)}
    {#if editingPath === node.path}
      <input
        bind:value={editValue}
        onblur={saveEdit}
        onkeydown={(e) => e.key === 'Enter' && saveEdit()}
        autofocus
      />
    {:else}
      <span ondblclick={() => startEdit(node)}>
        {node.data.name}
      </span>
    {/if}
  {/snippet}
</Tree>

BULK SUBTREE OPERATIONS (rc04+)
-------------------------------
Insert, replace, or delete entire subtrees with a single tree emission:

insertBranch(parentPath: string, data: T[]): InsertBranchResult<T>
- Inserts an array of nodes as a subtree under parentPath
- All nodes are inserted in one batch, triggering a single reactive update
- Returns { success, count, failed, parentNode }

replaceBranch(parentPath: string, data: T[]): InsertBranchResult<T>
- Removes the node at parentPath and all descendants, then inserts new nodes
- Useful for server-driven updates where a subtree is replaced wholesale
- Returns { success, count, failed, parentNode }

deleteBranch(path: string, keepParent?: boolean): DeleteBranchResult<T>
- Removes the node at path and all its descendants in one operation
- keepParent: keep the node itself, remove only its descendants
- Returns { success, removedCount, error? }

Example: server-driven cut/paste
<script>
  async function handlePaste(targetPath) {
    const response = await api.paste(clipboardData, targetPath);
    // Server returns the updated subtree
    treeRef.deleteBranch(clipboardData.sourcePath);
    treeRef.insertBranch(targetPath, response.newNodes);
  }
</script>

CLIPBOARD API
-------------
Built-in clipboard for copy/cut/paste workflows. These methods live on the
TreeController, NOT on the Tree component ref. Reach the controller via the
onTreeKeydown interceptor (ctx.controller) or hold your own reference. Below,
`controller` is that TreeController instance.

// Copy selected nodes (or specific paths)
controller.copyNodes();                 // copies highlightedPaths
controller.copyNodes(['1.2', '1.3']);   // copies specific paths

// Cut selected nodes (dims them visually, removes on paste)
controller.cutNodes();                  // cuts highlightedPaths
controller.cutNodes(['1.2']);           // cuts specific paths

// Paste at target node
controller.pasteNodes('2.1');           // paste as children of 2.1 (default)
controller.pasteNodes('2.1', null, 'after');  // paste as siblings after 2.1

// Delete nodes (highlightedPaths, or specific paths; honors beforeDeleteCallback)
controller.deleteNodes();               // returns { removed, blocked }
controller.deleteNodes(['1.2']);

// Cancel cut (removes dimming)
controller.cancelCut();

// Check clipboard state
controller.hasClipboardContent();       // boolean
controller.getClipboardOperation();     // 'copy' | 'cut' | null

Cut nodes are tracked via controller.cutPaths (Set<string>) and rendered at
reduced opacity.

pasteNodes signature:
pasteNodes(
  targetPath: string,
  transform?: (data: T, ctx: NodeTransformContext<T>) => T | null,
  position: 'child' | 'before' | 'after' = 'child'
)
- transform (optional) overrides pasteNodeTransformationCallback for this paste;
  return null from it to SKIP a node (skipping a root skips its subtree).
- position 'child' onto a node that disallows 'child' (a leaf/file) is redirected
  to paste beside it, honoring getAllowedDropPositionsCallback.
Returns: PasteResult = { success, count, skipped, error? }

BUILT-IN KEYBOARD SHORTCUTS
---------------------------
Set shouldHandleKeyboardShortcuts (default false) to enable Ctrl/Cmd+C/X/V,
Delete, Esc (cancel cut), plus classic aliases Ctrl+Insert / Shift+Insert /
Shift+Delete. Shortcuts are FOCUS-SCOPED to the tree's .stv__container
(tabindex=0): they only fire when focus is inside the tree.

CLIPBOARD CALLBACKS (props on <Tree>)
-------------------------------------
Interceptors (return value modifies/blocks the operation):

beforeCopyCallback / beforeCutCallback:
  (ctx: { operation, paths, nodes }) => string[] | false | void
  Return a new path[] to rewrite the set, or false to block.

beforePasteCallback:
  (ctx: { operation, target: { path, node }, entries }) => { targetPath?, position? } | false | void
  Redirect the target/position, or return false to block.

beforeDeleteCallback:
  (ctx: { paths, nodes }) => string[] | false | void
  Narrow the delete set (return path[]) or block it (false).

Per-node transforms (both take NodeTransformContext<T>):

copyNodeTransformationCallback: (data: T, ctx: NodeTransformContext<T>) => T
  Clean/redact fields at snapshot time (phase 'copy'; target + position null).

pasteNodeTransformationCallback: (data: T, ctx: NodeTransformContext<T>) => T | null
  Derive ids/values/names at insert (phase 'paste'); return null to skip.

NodeTransformContext<T> = {
  operation: 'copy' | 'cut';
  phase: 'copy' | 'paste';
  isRoot; index;
  position: 'child' | 'before' | 'after' | null;   // null during copy phase
  source: { path, node, parent, siblings };
  target: { path, node, parent, siblings } | null; // null during copy phase / at root
}

Collision-free names — use the exported uniqueName helper inside the paste
transform (import from '@keenmate/svelte-treeview'):

  import { uniqueName } from '@keenmate/svelte-treeview';
  pasteNodeTransformationCallback={(data, ctx) => {
    const landing = ctx.position === 'child' && ctx.target?.node
      ? Object.values(ctx.target.node.children)
      : (ctx.target?.siblings ?? []);
    return { ...data, name: uniqueName(data.name, landing.map(s => s.data?.name)) };
  }}

uniqueName(base, taken, suffix?) — returns a collision-free name (default
`${base} Copy ${n}`).

BATCH OPERATIONS
----------------
Multiple operations at once:

<script>
  function batchUpdate() {
    // Disable reactivity during batch
    const operations = [
      () => treeRef.addNode('1', { name: 'Item A' }),
      () => treeRef.addNode('1', { name: 'Item B' }),
      () => treeRef.moveNode('2.1', '1', 'child')
    ];

    operations.forEach(op => op());

    // Refresh after batch
    treeRef.refreshSiblings('1');
  }
</script>

UNDO/REDO SUPPORT
-----------------
Track operations for undo:

<script>
  let history = $state([]);
  let historyIndex = $state(-1);

  function recordOperation(type, data, undo) {
    // Clear redo history
    history = history.slice(0, historyIndex + 1);
    // Add new operation
    history = [...history, { type, data, undo }];
    historyIndex = history.length - 1;
  }

  function addNode(parentPath, nodeData) {
    const result = treeRef.addNode(parentPath, nodeData);
    if (result.success) {
      recordOperation('add', result.node, () => {
        treeRef.removeNode(result.node.path);
      });
    }
  }

  function undo() {
    if (historyIndex >= 0) {
      history[historyIndex].undo();
      historyIndex--;
    }
  }
</script>

SYNC WITH SERVER
----------------
<script>
  async function addNodeWithSync(parentPath, nodeData) {
    // Optimistic update
    const result = treeRef.addNode(parentPath, nodeData);

    if (result.success) {
      try {
        // Sync to server
        await api.createNode({
          ...nodeData,
          path: result.node.path
        });
      } catch (error) {
        // Rollback on failure
        treeRef.removeNode(result.node.path);
        showError('Failed to save');
      }
    }
  }
</script>

BEST PRACTICES
--------------
✅ Use orderMember for proper sibling ordering
✅ Handle operation results (success/error)
✅ Expand parent after adding child
✅ Update selection after operations
✅ Sync with server if needed
✅ Consider undo/redo for complex apps

❌ Don't forget to set orderMember
❌ Don't assume operations always succeed
❌ Don't mutate data directly (use methods)
❌ Don't forget to refresh UI after batch operations
