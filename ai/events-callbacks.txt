EVENTS AND CALLBACKS
====================

CRITICAL: Event-driven architecture
- on* events are FIRE-AND-FORGET notifications
- Every on* event takes exactly ONE context object (NOT positional args)
- before*/get* callbacks intercept or provide data (beforeDropCallback stays positional)
- Context objects carry NodeRef<T> = { path, node, parent, siblings } (live, or null/[] cross-tree)

NODE CLICK
----------
<Tree
  onNodeClick={(ctx) => {
    const node = ctx.node;  // clicked node (null if unreachable)
    console.log('Clicked:', node.data.name);
    console.log('Path:', ctx.path);
    console.log('Level:', node.level);
    console.log('Parent:', ctx.parent?.data.name);
    console.log('Siblings:', ctx.siblings.length);
  }}

  onNodeDoubleClick={(ctx) => {
    console.log('Double-clicked:', ctx.node.data.name);
  }}
/>

Click behavior (default: 'expand-and-focus'):
<Tree clickBehavior="select" />

'select' = click selects, double-click expands/collapses.
'expand' = click expands/collapses only, no selection.
'expand-and-focus' = click selects + expands/collapses.

DRAG EVENTS
-----------
Each drag event takes ONE ctx. A drag is single-origin, so dragStart/dragOver/drop
each fire ONCE even for a multi-selection; ctx.dragged carries the full top-level set.

<Tree
  onNodeDragStart={(ctx) => {
    // ctx = NodeRef + { event, dragged }; ctx.node is the grabbed node
    console.log('Started dragging:', ctx.node.data.name);
    console.log('In flight:', ctx.dragged.length);  // NodeRef[]
    // Can modify ctx.event.dataTransfer here
  }}

  onNodeDragOver={(ctx) => {
    // ctx.node is the HOVERED node; ctx.dragged is the in-flight set
    console.log('Dragging over:', ctx.node.data.name);
  }}

  onNodeDrop={(ctx) => {
    // ctx = NodeDropContext { source, target, dragged, dropped, position, operation, event }
    console.log('Dropped:', ctx.source.node.data.name);   // lead dragged node
    console.log('Target:', ctx.target?.node.data.name);   // drop node; target null = empty/root
    console.log('Position:', ctx.position);   // 'before', 'after', 'child'
    console.log('Operation:', ctx.operation); // 'move', 'copy'
    console.log('Whole set:', ctx.dragged.length);        // full top-level dragged set
    // dropped = nodes the LIBRARY placed (move: moved nodes; copy: fresh copies);
    // null cross-tree or when shouldAutoHandleMove/Copy=false (you insert)
    console.log('Placed:', ctx.dropped?.length ?? 'consumer-handled');
  }}
/>

SELECTION EVENTS
----------------
Fire after highlight (UI multi-select) or checkbox selection changes.
Both take SelectionChangeContext { paths: Set<string>, nodes: LTreeNode<T>[] }.
Suppressed by { silent: true } mutations.

<Tree
  onHighlightChange={(ctx) => {
    // highlightedPaths (Ctrl/Shift+click UI set) changed
    console.log('Highlighted:', ctx.paths.size, 'nodes:', ctx.nodes.length);
  }}

  onSelectionChange={(ctx) => {
    // selectedPaths (checkbox data set) changed
    console.log('Selected:', [...ctx.paths]);
  }}
/>

CLIPBOARD EVENTS
----------------
Fire after clipboard/delete operations. onCopy/onCut/onDelete take
ClipboardEventContext { operation?: 'copy'|'cut', paths, nodes }
(operation omitted for delete). onPaste takes the PasteResult.

<Tree
  onCopy={(ctx) => {
    // ctx = { operation: 'copy', paths, nodes } — nodes live
    console.log('Copied:', ctx.paths);
  }}

  onCut={(ctx) => {
    // ctx = { operation: 'cut', paths, nodes } — nodes still live (dimmed until paste)
    console.log('Cut:', ctx.paths);
  }}

  onDelete={(ctx) => {
    // ctx = { paths, nodes } (no operation) — nodes are PRE-REMOVAL snapshots
    console.log('Deleted:', ctx.nodes.map((n) => n.data.name));
  }}

  onPaste={(result) => {
    // result = PasteResult { success, count, skipped, error? }
    console.log('Pasted:', result.count, 'skipped:', result.skipped);
  }}
/>

TREE KEYDOWN (INTERCEPTOR)
--------------------------
Not fire-and-forget: onTreeKeydown intercepts keydown before default + built-in
shortcuts. Return true to suppress them. Focus-scoped to .stv__container.
ctx = { event, focusedNode, highlightedNodes, controller }.

<Tree
  onTreeKeydown={(ctx) => {
    if (ctx.event.key === 'Enter' && ctx.focusedNode) {
      openItem(ctx.focusedNode.data);
      return true;  // suppress default handling
    }
    // ctx.controller for imperative actions (copyNodes, pasteNodes, ...)
  }}
/>

BEFORE DROP CALLBACK
--------------------
NOTE: beforeDropCallback is DELIBERATELY still 5-arg positional (the only
un-migrated callback). Validate or modify drops before they happen:

<Tree
  beforeDropCallback={async (dropNode, draggedNode, position, event, operation) => {
    // Cancel the drop
    if (draggedNode.data.locked) {
      return false;
    }

    // Show confirmation
    if (!await confirm('Are you sure?')) {
      return false;
    }

    // Modify position
    if (position === 'child' && dropNode.data.type === 'file') {
      return { position: 'after' };
    }

    // Modify operation
    if (event.shiftKey) {
      return { operation: 'copy' };
    }

    // Proceed normally
    return true;
  }}
/>

Return values:
- false → Cancel drop
- true / undefined → Proceed normally
- { position: 'before'|'after'|'child' } → Override position
- { operation: 'move'|'copy' } → Override operation
- { position, operation } → Override both
- Promise<...> → Async validation

DISPLAY VALUE CALLBACK
----------------------
Compute display text dynamically:

<Tree
  getDisplayValueCallback={(node) => {
    const item = node.data;
    return `${item.firstName} ${item.lastName}`;
  }}
/>

Complex example:
<Tree
  getDisplayValueCallback={(node) => {
    const item = node.data;
    const count = item.children?.length || 0;
    const suffix = count > 0 ? ` (${count})` : '';
    return `${item.name}${suffix}`;
  }}
/>

SEARCH VALUE CALLBACK
---------------------
Control what text gets indexed for search:

<Tree
  getSearchValueCallback={(node) => {
    const item = node.data;
    return `${item.name} ${item.email} ${item.tags.join(' ')}`;
  }}
/>

ALLOWED DROP POSITIONS CALLBACK
-------------------------------
Control which drop positions are allowed per node:

<Tree
  getAllowedDropPositionsCallback={(node) => {
    if (node.data.type === 'file') return ['before', 'after'];
    if (node.data.type === 'trash') return ['child'];
    return undefined;  // all positions
  }}
/>

CONTEXT MENU CALLBACK
---------------------
Generate context menu items dynamically:

<Tree
  getContextMenuItemsCallback={(node, closeMenuCallback) => {
    return [
      {
        icon: '📂',
        label: 'Open',
        onclick: () => {
          openItem(node.data);
          closeMenuCallback();
        }
      },
      { divider: true },
      {
        icon: '🗑️',
        label: 'Delete',
        className: 'danger',
        isDisabled: node.data.isProtected,
        onclick: async () => {
          if (await confirmDelete()) {
            deleteItem(node.data);
            closeMenuCallback();
          }
        }
      }
    ];
  }}
/>

SORT CALLBACK
-------------
Custom sorting for tree display:

<Tree
  sortCallback={(nodes) => {
    return nodes.sort((a, b) => {
      // Sort by level first (required for proper tree construction)
      const aLevel = a.path.split('.').length;
      const bLevel = b.path.split('.').length;
      if (aLevel !== bLevel) return aLevel - bLevel;

      // Then by your criteria
      return (a.data?.name ?? '').localeCompare(b.data?.name ?? '');
    });
  }}
/>

INITIALIZE INDEX CALLBACK
-------------------------
Custom FlexSearch index configuration:

<Tree
  initializeIndexCallback={() => {
    return new Index({
      tokenize: 'forward',
      resolution: 9,
      cache: true
    });
  }}
/>

BINDING VS CALLBACK
-------------------
Bindable props (two-way):
- searchText
- focusedNode (single focused node)
- highlightedPaths (Set<string>, Ctrl/Shift+click highlight)
- selectedPaths (Set<string>, checkbox data state)
- insertResult

Callback props (one-way notification):
- onNodeClick
- onNodeDoubleClick
- onNodeDrop
- onNodeDragStart
- onNodeDragOver
- onHighlightChange
- onSelectionChange
- onCopy / onCut / onPaste / onDelete
- onTreeKeydown (interceptor)

Example combining both:

<script>
  let selectedNode = $state(null);

  function handleClick(ctx) {
    // Called in addition to selectedNode update
    console.log('Clicked:', ctx.path);
    analytics.track('node_click', { path: ctx.path });
  }
</script>

<Tree
  bind:focusedNode
  onNodeClick={handleClick}
/>

CALLBACK SIGNATURES
-------------------
All on* events take ONE ctx object (fire-and-forget), except onTreeKeydown.

NodeRef<T> = { path, node, parent, siblings }  // node/parent/siblings null/[] cross-tree

onNodeClick / onNodeDoubleClick:
(ctx: NodeRef<T>) => void

onNodeDragStart / onNodeDragOver:
(ctx: NodeDragContext<T>) => void
  // NodeDragContext = NodeRef<T> & { event: DragEvent, dragged: NodeRef<T>[] }

onNodeDrop:
(ctx: NodeDropContext<T>) => void
  // NodeDropContext = {
  //   source: NodeRef<T>,           // lead dragged node
  //   target: NodeRef<T> | null,    // drop node; null = empty/root
  //   dragged: NodeRef<T>[],        // full top-level dragged set
  //   dropped: NodeRef<T>[] | null, // library-placed nodes; null cross-tree / auto-handle off
  //   position: 'before' | 'after' | 'child',
  //   operation: 'move' | 'copy',
  //   event: DragEvent | TouchEvent
  // }

onHighlightChange / onSelectionChange:
(ctx: SelectionChangeContext<T>) => void
  // SelectionChangeContext = { paths: Set<string>, nodes: LTreeNode<T>[] }

onCopy / onCut / onDelete:
(ctx: ClipboardEventContext<T>) => void
  // ClipboardEventContext = { operation?: 'copy' | 'cut', paths: string[], nodes: LTreeNode<T>[] }
  // operation omitted for onDelete

onPaste:
(result: PasteResult<T>) => void
  // PasteResult = { success, count, skipped, error? }

onTreeKeydown (interceptor — return true to suppress default + built-in shortcuts):
(ctx: { event, focusedNode, highlightedNodes, controller }) => boolean | void

beforeDropCallback (deliberately still 5-arg positional):
(
  dropNode: LTreeNode<T> | null,
  draggedNode: LTreeNode<T>,
  position: 'before' | 'after' | 'child',
  event: DragEvent,
  operation: 'move' | 'copy'
) => boolean | { position?, operation? } | Promise<...>

getDisplayValueCallback:
(node: LTreeNode<T>) => string

getSearchValueCallback:
(node: LTreeNode<T>) => string

getAllowedDropPositionsCallback:
(node: LTreeNode<T>) => DropPosition[] | null | undefined

getContextMenuItemsCallback:
(node: LTreeNode<T>, closeMenu: () => void, selectedNodes?: LTreeNode<T>[]) => ContextMenuEntry[]

sortCallback:
(nodes: LTreeNode<T>[]) => LTreeNode<T>[]

initializeIndexCallback:
() => Index

ASYNC CALLBACKS
---------------
These callbacks support async/Promise:

- beforeDropCallback (awaited before drop)
- getContextMenuItemsCallback item onclick handlers (individual actions)

Example async beforeDropCallback:
beforeDropCallback={async (drop, drag, pos) => {
  const allowed = await checkPermission(drag.data);
  return allowed;
}}

Example async context menu:
{
  label: 'Save',
  onclick: async () => {
    await saveToServer();
    closeMenu();
  }
}

ERROR HANDLING
--------------
Handle errors in async callbacks:

beforeDropCallback={async (drop, drag, pos) => {
  try {
    await validateMove(drag, drop);
    return true;
  } catch (error) {
    showError(error.message);
    return false;
  }
}}

Context menu with error handling:
{
  label: 'Delete',
  onclick: async () => {
    try {
      await deleteItem(node.data);
      closeMenu();
    } catch (error) {
      showError('Failed to delete');
      // Menu stays open
    }
  }
}

CALLBACK PRIORITY
-----------------
When both member and callback are set, callback wins:

getDisplayValueCallback > displayValueMember

<Tree
  displayValueMember="name"  // Ignored
  getDisplayValueCallback={(n) => n.data.title}  // Used
/>

COMMON PATTERNS
---------------
Selection tracking:
<script>
  let history = $state([]);
</script>

<Tree
  onNodeClick={(ctx) => {
    history = [...history, ctx.path];
  }}
/>

Prevent certain drops:
<Tree
  beforeDropCallback={(drop, drag) => {
    // Prevent dropping folders into files
    if (drag.data.type === 'folder' && drop?.data.type === 'file') {
      showError('Cannot drop folder into file');
      return false;
    }
    return true;
  }}
/>

Analytics integration:
<Tree
  onNodeClick={(ctx) => {
    analytics.track('tree_click', {
      path: ctx.path,
      type: ctx.node.data.type
    });
  }}
  onNodeDrop={(ctx) => {
    analytics.track('tree_drop', {
      from: ctx.source.path,
      to: ctx.target?.path,
      position: ctx.position
    });
  }}
/>

BEST PRACTICES
--------------
✅ Use callbacks for side effects (logging, analytics)
✅ Use bindings for state synchronization
✅ Handle errors in async callbacks
✅ Return early from beforeDropCallback for validation
✅ Close context menu after successful action

❌ Don't modify node data directly in callbacks
❌ Don't do heavy computation in callbacks
❌ Don't forget error handling in async callbacks
❌ Don't block UI with sync operations
